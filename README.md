## “双 ISP”说的是 IP 的注册属性，不是给你两个 IP

普通 VPS 的 IP 注册在机房或云厂商名下，IP 查询工具一查，归属显示 Hosting Company 或 Data Center。TikTok、Netflix、ChatGPT 这类平台的风控看到这种归属，会按批量访问处理，轻的限流，重的直接封号。

双 ISP 住宅 IP 要做的事，是让这个 IP 的 ASN 注册信息落在 ISP（互联网服务提供商）名下，多个 IP 数据库会把它标成家宽属性。在平台眼里，这台机器更像一条美国家庭宽带。

关于“双 ISP”这三个字，网上存在两种解释。一种说法是同一台机器同时接入两家 ISP 的线路，一条主用一条冗余；另一种说法是同一个 IP 在两个 ISP 名下都有注册记录，并不是分配两个 IP。后一种解释与其他商家的产品页一致：NovixLink 每个套餐都写明“1x 独享美国双 ISP 原生家宽 IPv4”，LisaHost 也明确默认单 IP，Akile 这三档同样是 1 个 IPv4。所以按“一个 IP、双 ISP 注册属性”理解更贴近实际配置。

这个事实对你预算的影响很直接。一个 IP 一个号是相对稳妥的做法，最多两个。要跑 5 个账号，就得开 5 台机器，成本按机器数乘，不是按账号数乘。很多人第一次买只算了一台的价钱，发现不够用再补，才发现总支出比预想翻了几倍。

## 4837、9929、CMIN2、国际带宽：四条线路的分工

线路决定的是你在国内操作这台机器时顺不顺，和 IP 属性是两件独立的事。

**AS4837 / CUVIP** 是联通的普通国际线路，做了中国大陆方向优化，定位性价比。Akile 这条双 ISP 产品线走的就是三网回程 CUVIP（4837），国内方向的延迟和稳定性属于可用水准，谈不上顶级。

**AS9929 / CUII** 是联通的精品网线路，全称 China Unicom Industrial Internet。业内常拿它和电信的 CN2 GIA 对比，两者都是花钱优化的高端线路，9929 对联通用户更友好，CN2 GIA 对电信用户更友好。这里有个流传很广的错误说法，把 9929 写成“中国电信的精品网”，CUII 的官方归属是联通，看到“电信 9929”的说法可以直接跳过。

**CMIN2** 是中国移动的下一代国际精品网，移动侧的回程优化靠它。

**国际带宽线路**则是另一回事。NovixLink 的 COX 系列在产品页上明确标注“双程 BGP 线路，不含中国大陆连接优化，建议自备跨境加速服务”，同时强调 IP 是美国本土真实家宽运营商 Cox Communications 直供。这句话很诚实：IP 属性给你了，国内访问快不快是另一笔钱。

所以选线路的顺序应该是先问自己人在哪操作。人在国内远程 SSH、上传视频、推流直播，回程优化直接决定体感，4837 起步、9929/CMIN2 更好。机器只是跑给美国本地用户和平台看，人很少连上去，那 IP 属性优先，线路可以省。

**双 ISP 是不是给两个 IP？**

不是。三档都是 1 个 IPv4，双 ISP 描述的是这个 IP 的注册属性，与数量无关。

**流量超了会停机吗？**

本文没有核到这条产品线对 Windows 的支持情况，需要直接问客服或在购买页确认。1 核 2G 的入门档跑 Windows 本身也偏紧。
